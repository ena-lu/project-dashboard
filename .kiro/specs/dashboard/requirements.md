# 需求文件：專案管理儀表板

## 專案概述

建立一個純前端的專案管理儀表板雛型，使用模擬資料呈現公司內部專案的執行狀況。不包含後端、登入、資料庫、即時資料或任何未列出的功能。

---

## 使用者故事與驗收條件

---

### US-01 查看所有專案列表

**身為**內部使用者，  
**我想要**在儀表板上看到所有進行中的專案，  
**以便**快速掌握公司目前的專案全貌。

**驗收條件：**
- [ ] 頁面載入後，顯示所有模擬專案的列表
- [ ] 每筆專案至少顯示：專案名稱、客戶名稱、目前狀態
- [ ] 每筆專案在列表中顯示「目前所處階段的預計完成日期」，格式為 YYYY-MM-DD
- [ ] 若目前階段無預計完成日期，顯示「—」
- [ ] 模擬資料涵蓋以下六種狀態，且每種至少有一筆：
  - 需求確認中
  - 待開案
  - 開發中
  - 測試中
  - 待發布
  - 已發布

---

### US-02 依狀態識別專案

**身為**內部使用者，  
**我想要**透過視覺標示區分專案狀態，  
**以便**一眼辨識各專案目前所處的階段。

**驗收條件：**
- [ ] 每種狀態以不同顏色的標籤（badge）顯示
- [ ] 六種狀態皆有對應的顏色，顏色不重複

---

### US-03 依客戶篩選專案

**身為**內部使用者，  
**我想要**依照客戶名稱篩選專案，  
**以便**只查看特定客戶的專案。

**驗收條件：**
- [ ] 頁面提供客戶篩選下拉選單，選項由模擬資料自動產生
- [ ] 選單包含「全部客戶」選項，為預設值
- [ ] 選擇特定客戶後，列表只顯示該客戶的專案
- [ ] 選回「全部客戶」後，恢復顯示所有專案

---

### US-04 查看專案各階段預計完成日期

**身為**內部使用者，  
**我想要**查看每個專案各階段的預計完成日期，  
**以便**了解專案時程規劃。

**驗收條件：**
- [ ] 每個專案可展開或進入詳細檢視
- [ ] 詳細檢視顯示以下階段的預計完成日期：需求確認、開案、開發、測試、發布
- [ ] 預計完成日期以模擬資料填入，格式為 YYYY-MM-DD

---

### US-05 填寫並顯示實際完成日期

**身為**內部使用者，  
**我想要**在各階段填寫實際完成日期，  
**以便**記錄實際執行進度。

**驗收條件：**
- [ ] 各階段的實際完成日期欄位可輸入（input type="date"）
- [ ] 若尚未填寫，欄位顯示為空白或佔位提示
- [ ] 填寫後，數值顯示在對應欄位中（不需持久化儲存）

---

### US-06 查看各階段預估與實際工時

**身為**內部使用者，  
**我想要**查看各階段的預估工時與實際工時，  
**以便**評估專案的工時掌握情況。

**驗收條件：**
- [ ] 各階段顯示預估工時（單位：小時），由模擬資料提供
- [ ] 各階段提供實際工時輸入欄位（number input）
- [ ] 若尚未填寫實際工時，欄位顯示為空白

---

### US-07 顯示預估與實際的差異

**身為**內部使用者，  
**我想要**看到預估與實際工時的差異，  
**以便**快速判斷專案是否超時或提早完成。

**驗收條件：**
- [ ] 當實際工時已填寫，自動計算並顯示差異值（實際 − 預估）
- [ ] 差異為正數（超時）時，以紅色顯示，並加上「+」符號
- [ ] 差異為負數（提早）時，以綠色顯示
- [ ] 差異為零時，以中性色顯示
- [ ] 若實際工時未填寫，差異欄位顯示「—」

### US-08 以甘特圖檢視所有專案時程

**身為**內部使用者，  
**我想要**切換到甘特圖檢視模式，  
**以便**一眼看清所有專案各階段的時間分布與進度。

**驗收條件：**
- [ ] 頁面提供「列表」與「甘特圖」的切換按鈕
- [ ] 預設顯示列表檢視；點擊甘特圖按鈕後切換為甘特圖
- [ ] 甘特圖以原生 SVG 或 CSS 實作，不引入外部套件
- [ ] 甘特圖 X 軸為時間軸，Y 軸每列代表一個專案
- [ ] 每個專案顯示 5 個階段的時間區段（依 plannedDate 計算起訖）
  - 每個階段的起始日為上一個階段的 plannedDate 隔日（第一個階段起始日為最早的 plannedDate 往前推 30 天）
  - 若某階段 plannedDate 為空，該區段不顯示
- [ ] 進入甘特圖時，時間軸預設置中於今日（以 `new Date()` 取得當日日期）
- [ ] 今日在時間軸上以明顯垂直線標示
- [ ] 客戶篩選套用至甘特圖（切換客戶後甘特圖同步更新）

---

### US-09 依狀態篩選專案

**身為**內部使用者，  
**我想要**依照專案狀態篩選專案，  
**以便**只查看特定狀態的專案。

**驗收條件：**
- [ ] 頁面提供狀態篩選下拉選單，選項包含：
  - 全部狀態（預設）
  - 需求確認中
  - 待開案
  - 開發中
  - 測試中
  - 待發布
  - 已發布
- [ ] 選擇特定狀態後，列表只顯示該狀態的專案
- [ ] 選回「全部狀態」後，恢復顯示所有專案
- [ ] 狀態篩選與客戶篩選可同時使用（交集）

---

### US-10 依欄位排序專案

**身為**內部使用者，  
**我想要**依照客戶、狀態或預計完成日期來排序專案列表，  
**以便**以不同順序檢視專案。

**驗收條件：**
- [ ] 頁面提供排序下拉選單，選項包含：
  - 不排序（預設）
  - 客戶（遞增 a-z）
  - 狀態（依狀態順序：需求確認中 → 待開案 → 開發中 → 測試中 → 待發布 → 已發布）
  - 預計完成日期（遞增，早到晚）
- [ ] 選擇排序方式後，列表即時重新排列
- [ ] 排序與篩選可同時使用（先篩選再排序）

---

### US-11 依 PM 篩選專案

**身為**內部使用者，  
**我想要**依照負責 PM 篩選專案，  
**以便**只查看特定 PM 負責的專案。

**驗收條件：**
- [ ] 每筆專案顯示負責 PM 名稱
- [ ] 頁面提供 PM 篩選下拉選單，選項由模擬資料自動產生
- [ ] 選單包含「全部 PM」選項，為預設值
- [ ] 選擇特定 PM 後，列表只顯示該 PM 負責的專案
- [ ] 選回「全部 PM」後，恢復顯示所有專案
- [ ] PM 篩選可與客戶篩選、狀態篩選同時使用（交集）

---

### US-12 甘特圖日期區間篩選

**身為**內部使用者，  
**我想要**在甘特圖中篩選日期區間，  
**以便**只看見特定時間範圍內的專案時程。

**驗收條件：**
- [ ] 甘特圖檢視模式下，顯示開始日期與結束日期的篩選輸入框
- [ ] 預設值為今日往前 14 天至往後 14 天
- [ ] 變更日期後，甘特圖即時更新顯示範圍
- [ ] 日期區間與專案篩選（客戶、狀態、PM）可同時使用

---

## 範圍限制

- 不實作登入、權限管理
- 不串接任何外部 API 或後端服務
- 資料變更不需要持久化（重新整理後可還原為模擬資料）
- 不實作新增、刪除專案功能
- 甘特圖僅顯示 plannedDate 時程，不顯示統計報表
